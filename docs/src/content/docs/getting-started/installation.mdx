## Prerequisites

Effect GraphQL requires:
- Node.js 22.19.0 or later for Node.js integrations (required by `@effect/platform-node` 4.1.1), or Bun 1.4.2 or later for `@effect-gql/bun`
- TypeScript 5.9.3 (the version verified with these examples)

The Bun server checks its runtime version before starting. Earlier Bun releases
can leave rejected WebSocket connections counted as active, preventing shutdown.

## Install Dependencies

```bash
npm install @effect-gql/core effect@^4.1.1 graphql
```

This installs:
- `@effect-gql/core` - The core library
- `effect` - The Effect runtime and Schema library
- `graphql` - GraphQL.js for schema execution

Effect GraphQL targets stable **Effect 4.1.1**. Use matching **4.1.1** versions of
`@effect/platform-node`, `@effect/platform-bun`, and `@effect/opentelemetry`
when using those integrations. HTTP modules are included in `effect/http`;
the Effect 3-only `@effect/platform` package is no longer required.

### Migrating from Effect 3

Service classes now use `Context.Service<Self, Shape>()("Name")`. Schema
refinements use `.check(S.isMinLength(1))`, and multiple literals use
`S.Literals(["A", "B"])`. Replace `Effect.catchAll` with `Effect.catch`.

GraphQL routers are route-registration layers rather than pipeable routers:
compose them with `Layer.mergeAll(HttpRouter.add("GET", "/health", handler), graphqlRoutes)`.
Pass the resulting layer to `serve` or `toHandler`. Low-level GraphQL contexts
contain `services: Context.Context<R>`; obtain these with `Effect.context<R>()`
and run effects using `Effect.runPromiseWith(services)(effect)`. Keep scoped
services alive for the full request or subscription lifetime.

## TypeScript Configuration

For the best experience, ensure your `tsconfig.json` includes:

```json
{
  "compilerOptions": {
    "strict": true,
    "target": "ES2022",
    "lib": ["ES2024", "DOM"],
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "esModuleInterop": true,
    "skipLibCheck": true
  }
}
```

Key settings:
- `strict: true` - Enables full type checking (required for Effect)
- `target: ES2022` with `lib: ["ES2024", "DOM"]` - Modern runtime APIs and web-standard request/response types
- `moduleResolution: NodeNext` - Proper ESM resolution

## Verify Installation

Create a simple test file to verify everything is working:

```typescript
// test-install.ts
import { Effect } from "effect"
import * as S from "effect/Schema"
import { GraphQLSchemaBuilder } from "@effect-gql/core"

const schema = GraphQLSchemaBuilder.empty
  .query("hello", {
    type: S.String,
    resolve: () => Effect.succeed("world"),
  })
  .buildSchema()

console.log("Schema created successfully!")
console.log("Query type:", schema.getQueryType()?.name)
```

Run it:

```bash
npx tsx test-install.ts
```

You should see:

```
Schema created successfully!
Query type: Query
```
