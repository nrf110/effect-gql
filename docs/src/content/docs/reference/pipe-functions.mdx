---
title: Pipe Functions
description: Standalone functions for the pipe API
---

Effect GraphQL provides standalone functions that can be used with `.pipe()` for a more functional composition style.

## Import

```typescript
import {
  query,
  mutation,
  subscription,
  objectType,
  interfaceType,
  unionType,
  enumType,
  inputType,
  field,
  directive
} from "@effect-gql/core"
```

## Usage

All functions are designed to work with `GraphQLSchemaBuilder.pipe()`:

```typescript
import { GraphQLSchemaBuilder, query, objectType, field } from "@effect-gql/core"

const builder = GraphQLSchemaBuilder.empty.pipe(
  objectType({ name: "User", schema: UserSchema }),
  query("users", {
    type: S.Array(UserSchema),
    resolve: () => Effect.succeed([...])
  }),
  field("User", "posts", {
    type: S.Array(PostSchema),
    resolve: (user: S.Schema.Type<typeof UserSchema>) => Effect.succeed([...])
  })
)
```

## Root Operations

### `query(name, config)`

Add a Query field to the builder.

```typescript
query("users", {
  type: S.Array(UserSchema),
  args: S.Struct({ limit: S.optional(S.Number) }),
  description: "Get all users",
  resolve: ({ limit }) => Effect.succeed([...])
})
```

**Core signature** (additional field options are shared with the builder method):
```typescript
declare function query<A, E, R, Args = void, RArgs = never>(
  name: string,
  config: {
    type: S.Schema<A>
    args?: S.Decoder<Args, RArgs>
    description?: string
    resolve: (args: Args) => Effect.Effect<A, E, R>
  }
): SchemaOperation<R | RArgs>
```


`SchemaOperation<R>` is exported from `@effect-gql/core`. It accepts a
`GraphQLSchemaBuilder<RIn>` and returns `GraphQLSchemaBuilder<RIn | R>`.
Arguments are whole-schema decoders, normally `S.Struct({...})`; callbacks receive
decoded values, and decoder services accumulate alongside resolver services.

### `mutation(name, config)`

Add a Mutation field to the builder.

```typescript
mutation("createUser", {
  type: UserSchema,
  args: S.Struct({
    name: S.String,
    email: S.String
  }),
  resolve: ({ name, email }) => Effect.gen(function* () {
    const db = yield* Database
    return yield* db.createUser({ name, email })
  })
})
```

### `subscription(name, config)`

Add a Subscription field. `subscribe(args)` sets up a Stream; optional
`resolve(value, args)` runs an Effect per event using the same decoded arguments.

```typescript
subscription("messageAdded", {
  type: MessageSchema,
  args: S.Struct({ channelId: S.String }),
  subscribe: ({ channelId }) => Effect.gen(function* () {
    const pubsub = yield* PubSubService
    return pubsub.subscribe(`channel:${channelId}`)
  }),
  resolve: (message, _args) => Effect.succeed(message),
})
```

## Type Definitions

### `objectType(config)`

Register a GraphQL Object type.

```typescript
objectType({
  name: "User",
  schema: S.Struct({
    id: S.String,
    name: S.String,
    email: S.String
  }),
  description: "A user in the system"
})

// With TaggedStruct (name is inferred)
objectType({
  schema: S.TaggedStruct("User", {
    id: S.String,
    name: S.String
  })
})
```

### `interfaceType(config)`

Register a GraphQL Interface type.

```typescript
interfaceType({
  name: "Node",
  schema: S.Struct({
    id: S.String
  })
})
```

### `unionType(config)`

Register a GraphQL Union type.

```typescript
unionType({
  name: "SearchResult",
  types: ["User", "Post", "Comment"],
  resolveType: (value) => {
    if ("email" in value) return "User"
    if ("title" in value) return "Post"
    return "Comment"
  }
})
```

### `enumType(config)`

Register a GraphQL Enum type.

```typescript
// Simple enum
enumType({
  name: "Status",
  values: ["ACTIVE", "INACTIVE", "PENDING"]
})

// Type-level descriptions are supported; per-value configuration is not.
enumType({
  name: "Priority",
  values: ["LOW", "MEDIUM", "HIGH"],
  description: "Task priority"
})
```

### `inputType(config)`

Register a GraphQL Input type.

```typescript
inputType({
  name: "CreateUserInput",
  schema: S.Struct({
    name: S.String,
    email: S.String,
    role: S.optional(S.String)
  })
})
```

## Field Registration

### `field(typeName, fieldName, config)`

Add a field to an existing object type.

```typescript
field("User", "posts", {
  type: S.Array(PostSchema),
  args: S.Struct({
    limit: S.optional(S.Number),
    offset: S.optional(S.Number)
  }),
  description: "Posts authored by this user",
  resolve: (user: S.Schema.Type<typeof UserSchema>, { limit, offset }) => Effect.gen(function* () {
    const db = yield* Database
    return yield* db.getPostsByUserId(user.id, { limit, offset })
  })
})
```

**Core signature:**
```typescript
declare function field<Parent, A, E, R, Args = void, RArgs = never>(
  typeName: string,
  fieldName: string,
  config: {
    type: S.Schema<A>
    args?: S.Decoder<Args, RArgs>
    description?: string
    resolve: (parent: Parent, args: Args) => Effect.Effect<A, E, R>
  }
): SchemaOperation<R | RArgs>
```

Separate `field` calls require an explicit parent annotation; a type-name string
does not infer it. Inline `objectType({ fields: ... })` fields infer the parent.
Both `query` and `field` also support `directives`, `complexity`, and `cacheControl`.
Neither supports a `deprecationReason` option.

## Directives

### `directive(config)`

Register a custom directive.

```typescript
import { DirectiveLocation } from "graphql"

const withTrace = directive({
  name: "trace",
  locations: [DirectiveLocation.FIELD_DEFINITION],
  args: S.Struct({ label: S.String }),
  description: "Log selected field resolutions",
  apply: ({ label }) => (effect) =>
    Effect.logInfo(label).pipe(Effect.andThen(effect)),
})

const tracedBuilder = GraphQLSchemaBuilder.empty.pipe(
  withTrace,
  query("hello", {
    type: S.String,
    directives: [{ name: "trace", args: { label: "Resolving hello" } }],
    resolve: () => Effect.succeed("world"),
  }),
)
```

The curried `apply(args)(effect)` wrapper runs only where the directive is
explicitly applied. Its generic signature preserves the wrapped effect's error
type; it cannot introduce a new typed error. Put fallible authorization in the
resolver. For service-dependent wrappers, explicit `directive<Args, Services>`
type arguments may be necessary.

**Directive Locations:**
- `QUERY`, `MUTATION`, `SUBSCRIPTION`
- `FIELD`, `FIELD_DEFINITION`
- `OBJECT`, `INTERFACE`, `UNION`, `ENUM`, `INPUT_OBJECT`
- `SCALAR`, `ARGUMENT_DEFINITION`, `ENUM_VALUE`, `INPUT_FIELD_DEFINITION`

## Composition Patterns

### Sequential Registration

```typescript
const builder = GraphQLSchemaBuilder.empty.pipe(
  // Types first
  objectType({ name: "User", schema: UserSchema }),
  objectType({ name: "Post", schema: PostSchema }),

  // Then queries
  query("users", { ... }),
  query("posts", { ... }),

  // Then relational fields
  field("User", "posts", { ... }),
  field("Post", "author", { ... })
)
```

### Modular Composition

```typescript
// users.ts
export const userModule = <R>(builder: GraphQLSchemaBuilder<R>) =>
  builder.pipe(
    objectType({ name: "User", schema: UserSchema }),
    query("users", { ... }),
    query("user", { ... }),
    mutation("createUser", { ... })
  )

// posts.ts
export const postModule = <R>(builder: GraphQLSchemaBuilder<R>) =>
  builder.pipe(
    objectType({ name: "Post", schema: PostSchema }),
    query("posts", { ... }),
    field("User", "posts", { ... })
  )

// schema.ts
const builder = GraphQLSchemaBuilder.empty.pipe(
  userModule,
  postModule
)
```

### Conditional Registration

```typescript
const withAdminFeatures = process.env.ENABLE_ADMIN === "true"

const base = GraphQLSchemaBuilder.empty.pipe(
  query("users", { ... }),
)

const builder = withAdminFeatures
  ? base.pipe(
      query("adminStats", { ... }),
      mutation("deleteUser", { ... }),
    )
  : base
```

## Type Inference

All pipe functions correctly infer and accumulate service requirements:

```typescript
const builder = GraphQLSchemaBuilder.empty.pipe(
  query("users", {
    type: S.Array(UserSchema),
    resolve: () => Effect.gen(function* () {
      const db = yield* Database     // Adds Database to R
      return yield* db.getUsers()
    })
  }),

  query("posts", {
    type: S.Array(PostSchema),
    resolve: () => Effect.gen(function* () {
      const cache = yield* CacheService  // Adds CacheService to R
      return yield* cache.getPosts()
    })
  })
)
// Type: GraphQLSchemaBuilder<Database | CacheService>
```
