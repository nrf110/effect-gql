This example demonstrates real-time GraphQL subscriptions using Effect Streams. Clients can subscribe to events and receive updates as they happen.

## Running the Example

```bash
pnpm example:subscriptions
# Server starts at http://localhost:4002
# GraphiQL available at http://localhost:4002/graphiql
# WebSocket endpoint: ws://localhost:4002/graphql
```

## What You'll Learn

- Defining subscriptions with Effect Streams
- Using subscriptions with arguments
- Broadcasting messages with Effect PubSub
- WebSocket transport with graphql-ws protocol

## Subscription Basics

Subscriptions in Effect GQL use Effect Streams to emit values over time:

```typescript
import { Effect, Stream, Duration, Schedule } from "effect"

subscription("tick", {
  type: Tick,
  description: "Emits a tick every second",
  subscribe: () =>
    Effect.succeed(
      Stream.iterate(1, (n) => n + 1).pipe(
        Stream.schedule(Schedule.spaced(Duration.seconds(1))),
        Stream.map((count) => ({
          count,
          timestamp: Date.now(),
        }))
      )
    ),
})
```

## Subscriptions with Arguments

Subscriptions can accept arguments just like queries:

```typescript
subscription("countdown", {
  type: S.Int,
  args: S.Struct({ from: S.Int }),
  description: "Counts down from a number to zero",
  subscribe: ({ from }) =>
    Effect.succeed(
      Stream.range(0, from).pipe(
        Stream.map((i) => from - i),
        Stream.schedule(Schedule.spaced(Duration.seconds(1)))
      )
    ),
})
```

## Broadcasting with PubSub

For real-time messaging, use Effect's PubSub to broadcast to all subscribers:

```typescript
import { Effect, PubSub } from "effect"

// Create a PubSub for messages
const messagePubSub = Effect.runSync(PubSub.unbounded<Message>())

// Mutation publishes to PubSub
mutation("sendMessage", {
  args: S.Struct({ content: S.String, author: S.String }),
  type: Message,
  resolve: (args) =>
    Effect.gen(function* () {
      const message: Message = {
        id: String(++messageIdCounter),
        content: args.content,
        author: args.author,
        createdAt: Date.now(),
      }
      
      // Broadcast to all subscribers
      yield* PubSub.publish(messagePubSub, message)
      
      return message
    }),
})

// Subscription receives from PubSub
subscription("newMessage", {
  type: Message,
  description: "Receive real-time message updates",
  subscribe: () =>
    Effect.gen(function* () {
      const queue = yield* PubSub.subscribe(messagePubSub)
      return Stream.fromSubscription(queue)
    }),
})
```

## Filtered Subscriptions

Filter subscription streams based on arguments:

```typescript
subscription("messagesByAuthor", {
  type: Message,
  args: S.Struct({ author: S.String }),
  description: "Receive messages from a specific author",
  subscribe: ({ author }) =>
    Effect.gen(function* () {
      const queue = yield* PubSub.subscribe(messagePubSub)
      return Stream.fromSubscription(queue).pipe(
        Stream.filter((msg) => msg.author === author)
      )
    }),
})
```

## Enabling WebSocket Support

To enable subscriptions over WebSocket, pass the schema to the server options:

```typescript
import { serve } from "@effect-gql/node"

serve(app, Layer.empty, {
  port: 4002,
  subscriptions: {
    schema,
    path: "/graphql",
  },
  onStart: (url) => {
    Effect.runSync(Effect.logInfo("Subscription server ready", {
      url,
      websocket: "ws://localhost:4002/graphql",
    }))
  },
})
```

<Aside type="note">
WebSocket subscriptions require the optional `ws` peer dependency. Install it with
`npm install ws` when using `@effect-gql/node` subscriptions.
</Aside>

<Aside type="caution">
The current Node.js adapter has a
[WebSocket initialization limitation](/effect-gql/guides/subscriptions/#websocket-transport):
an immediate first connection can close with code `4408`, even while the HTTP
endpoint is healthy. Subsequent connections can succeed after initialization.
</Aside>

## Complete Code

```typescript
import { Effect, Stream, Layer, Duration, PubSub, Schedule } from "effect"
import * as S from "effect/Schema"
import { HttpRouter, HttpServerResponse } from "effect/http"
import {
  GraphQLSchemaBuilder,
  query,
  mutation,
  subscription,
  makeGraphQLRouter,
} from "@effect-gql/core"
import { graphiqlHtml } from "@effect-gql/core/server"
import { serve } from "@effect-gql/node"

// Domain models
const Tick = S.Struct({
  count: S.Number,
  timestamp: S.Number,
})

const Message = S.Struct({
  id: S.String,
  content: S.String,
  author: S.String,
  createdAt: S.Number,
})
type Message = S.Schema.Type<typeof Message>

// PubSub for broadcasting messages
let messageIdCounter = 0
const messagePubSub = Effect.runSync(PubSub.unbounded<Message>())

// Build schema
const schema = GraphQLSchemaBuilder.empty
  .pipe(
    query("hello", {
      type: S.String,
      resolve: () => Effect.succeed("Hello!"),
    }),

    mutation("sendMessage", {
      args: S.Struct({ content: S.String, author: S.String }),
      type: Message,
      resolve: (args) =>
        Effect.gen(function* () {
          const message = {
            id: String(++messageIdCounter),
            content: args.content,
            author: args.author,
            createdAt: Date.now(),
          }
          yield* PubSub.publish(messagePubSub, message)
          return message
        }),
    }),

    // Tick subscription
    subscription("tick", {
      type: Tick,
      subscribe: () =>
        Effect.succeed(
          Stream.iterate(1, (n) => n + 1).pipe(
            Stream.schedule(Schedule.spaced(Duration.seconds(1))),
            Stream.map((count) => ({ count, timestamp: Date.now() }))
          )
        ),
    }),

    subscription("countdown", {
      type: S.Int,
      args: S.Struct({ from: S.Int }),
      subscribe: ({ from }) => Effect.succeed(
        Stream.range(0, from).pipe(
          Stream.map((i) => from - i),
          Stream.schedule(Schedule.spaced(Duration.seconds(1)))
        )
      ),
    }),

    // New message subscription
    subscription("newMessage", {
      type: Message,
      subscribe: () =>
        Effect.gen(function* () {
          const queue = yield* PubSub.subscribe(messagePubSub)
          return Stream.fromSubscription(queue)
        }),
    }),

    subscription("messagesByAuthor", {
      type: Message,
      args: S.Struct({ author: S.String }),
      subscribe: ({ author }) => Effect.gen(function* () {
        const queue = yield* PubSub.subscribe(messagePubSub)
        return Stream.fromSubscription(queue).pipe(
          Stream.filter((message) => message.author === author)
        )
      }),
    }),
  )
  .buildSchema()

// Router and server setup
const graphqlRouter = makeGraphQLRouter(schema, Layer.empty, {
  path: "/graphql",
  graphiql: false,
})

const app = Layer.mergeAll(
  HttpRouter.add("GET", "/health", HttpServerResponse.json({ status: "ok" })),
  HttpRouter.add("GET", "/graphiql", HttpServerResponse.html(
    graphiqlHtml("/graphql", "ws://localhost:4002/graphql")
  )),
  graphqlRouter
)

serve(app, Layer.empty, {
  port: 4002,
  subscriptions: { schema, path: "/graphql" },
})
```

The broker is created once at process startup, outside request and connection
layers, so HTTP mutations and WebSocket subscriptions share the same PubSub.
The explicit GraphiQL route sets its WebSocket URL directly; use `wss://` when
serving behind HTTPS. The built-in GraphiQL configuration currently ignores a
custom `subscriptionEndpoint`, so use this route when setting that URL explicitly.

## Testing Subscriptions

### In GraphiQL

1. Open GraphiQL at `http://localhost:4002/graphiql`
2. Start a subscription:

```graphql
subscription {
  tick {
    count
    timestamp
  }
}
```

3. In another tab, subscribe to messages:

```graphql
subscription {
  newMessage {
    id
    content
    author
  }
}
```

4. Send a message via mutation:

```graphql
mutation {
  sendMessage(content: "Hello!", author: "Alice") {
    id
  }
}
```

The message will appear in the subscription tab.

### With a WebSocket Client

```javascript
import { createClient } from 'graphql-ws';

const client = createClient({
  url: 'ws://localhost:4002/graphql',
});

// Subscribe to ticks
const unsubscribe = client.subscribe(
  {
    query: 'subscription { tick { count timestamp } }',
  },
  {
    next: (data) => console.log('Tick:', data),
    error: (err) => console.error(err),
    complete: () => console.log('Complete'),
  }
);

// Later: unsubscribe()
```
